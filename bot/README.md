# ¡Vamos! — Telegram-бот для практики испанского

Бот помогает заниматься испанским вне приложения:

- **Тренировка дня.** Каждый день в выбранное время приходит 6 заданий: произношение, слова, грамматика, перевод, диктант на слух. Все задания взяты из курса приложения.
- **Разбор произношения.** Бот присылает фразу и образец озвучки, а ты отвечаешь голосовым сообщением. Бот распознаёт речь и сверяет каждое слово с эталоном. Для каждой ошибки он объясняет, что не так со звуком (RR, J, Z/C, LL, безударное O…), и даёт ударение по слогам. Ещё он присылает ссылки на **фрагменты реальных видео**, где носители произносят именно это слово или фразу (YouGlish находит момент в ролике и сразу запускает его), и записи носителей на Forvo.
- **Разговор с «носителем».** Можно говорить голосом или писать. Собеседник отвечает по-испански голосовым сообщением, присылает перевод и исправления. Темы: знакомство, кафе, путешествие, магазин, врач, свободная тема.
- **Слабые места.** Бот запоминает слова и звуки, на которых ты ошибаешься, и чаще даёт их в заданиях.
- **Свои фразы.** `/say ¿Dónde está la estación?` отправляет на проверку произношения любую фразу, например услышанную в фильме. `/word perro` показывает слоги, ударение, подсказки и ссылки на носителей.

Бот бесплатный: он работает на Cloudflare Workers, и распознавание, озвучка и собеседник тоже идут через Cloudflare Workers AI в рамках бесплатного дневного лимита. Банковская карта не нужна, компьютер держать включённым не нужно.

## Установка (≈10 минут, можно с телефона)

### 1. Создай бота в Telegram
1. Открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Придумай имя, например `Vamos Español`, и username, который заканчивается на `bot`, например `vamos_kolya_bot`.
3. Скопируй **токен** вида `1234567890:AAH...`.

### 2. Cloudflare (бесплатно)
1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com/sign-up).
2. Открой раздел **Workers & Pages** (Compute → Workers). Если Cloudflare предложит выбрать поддомен `*.workers.dev`, выбери любой.
3. Скопируй **Account ID**. Он показан справа на странице Workers & Pages и есть в адресной строке: `dash.cloudflare.com/<ACCOUNT_ID>/...`.
4. Создай API-токен: значок профиля → **My Profile → API Tokens → Create Token** → шаблон **Edit Cloudflare Workers** → *Use template*.
   - В блоке *Permissions* нажми **+ Add more** и добавь: `Account` · `Workers AI` · `Edit`.
   - *Account Resources*: твой аккаунт → **Continue to summary → Create Token**.
   - Скопируй токен. Cloudflare показывает его только один раз.

### 3. Секреты в GitHub
Открой репозиторий → **Settings → Secrets and variables → Actions → New repository secret** и добавь:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `CLOUDFLARE_API_TOKEN` | API-токен Cloudflare |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID |
| `ANTHROPIC_API_KEY` | *необязательно*: с ним собеседником будет Claude, иначе бесплатная модель Llama |

### 4. Запуск
**Actions → Telegram bot → Run workflow**. Примерно через 2 минуты в итогах запуска появится ссылка на бота. Открой её и нажми **Start**.

> Первый, кто напишет боту, становится его владельцем. Остальным бот ответит, что он личный, поэтому никто чужой не потратит твои лимиты.

После каждого изменения в папке `bot/` или в курсе приложения бот обновляется сам.

| | |
|---|---|
| 🎯 Упражнение, `/ex` | случайное задание (`/ex say`, `/ex listen`, `/ex tr`…) |
| 🎙 Произношение, `/say [фраза]` | фраза из курса или своя → голосовое → разбор |
| 💬 Разговор, `/chat` | разговор с носителем, `/stop` — закончить |
| 📅 Тренировка дня, `/daily` | 6 заданий подряд |
| `/word palabra` | слоги, ударение, подсказки по звукам, носители |
| 📊 Прогресс, `/stats` | опыт, серия дней, средний балл, трудные звуки и слова |
| ⚙️ Настройки, `/settings` | уровень A1/A2, Испания / Лат. Америка, время и часовой пояс, тема разговора |

## Как устроена проверка произношения

1. Голосовое распознаётся моделью Whisper (`whisper-large-v3-turbo`) в режиме испанского языка. Эталонную фразу модели не показывают, поэтому она не может подстроиться под правильный ответ.
2. Распознанные слова выравниваются с эталонными. Каждое слово получает отметку: ✅ верно, ⚠️ близко (например, *pero* вместо *perro*), ❌ неверно или не слышно. Из этих отметок складывается балл 0–100.
3. Для проблемных слов бот смотрит, какие буквы разошлись, и подбирает правило испанской фонетики именно для этого места. Правила учитывают вариант языка: [θ] в Испании и [s] в Латинской Америке, LL как [й] или [ш] и так далее.
4. Затем бот присылает образец озвучки (голос Deepgram Aura‑2), медленную версию проблемных слов и ссылки на моменты из реальных видео с носителями.

Распознавание не заменяет преподавателя-фонетиста. Но если слово распознаётся не так, его почти наверняка произнесли неточно, поэтому такая проверка хорошо ловит типичные ошибки.

## Для разработчика

```bash
cd bot
node scripts/build-content.mjs   # собрать упражнения из js/data/*.js
npm test                          # проверка контента, запасных моделей и полная симуляция диалогов с ботом
npx wrangler dev                  # локальный запуск (нужен KV и вход в Cloudflare)
```

Структура: `src/worker.js` — логика бота, `src/exercises.js` — задания, `src/pron.js` — разбор произношения (выравнивание, слоги, ударение, подсказки), `src/speech.js` — распознавание и озвучка, `src/chat.js` — собеседник, `src/content.js` — упражнения, собранные из курса.
